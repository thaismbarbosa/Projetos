# 🗂️ Gerenciador de Tarefas (To-Do List) em Python

Este é um projeto simples de terminal feito em Python para gerenciar tarefas. Ele permite ao usuário adicionar, listar, marcar como concluídas e filtrar tarefas por prioridade ou categoria.

## 🚀 Funcionalidades

- ✅ Adicionar novas tarefas com nome, descrição, prioridade e categoria
- 📋 Listar todas as tarefas cadastradas
- ✔️ Marcar tarefas como concluídas
- 🔍 Filtrar tarefas por:
  - Prioridade (Alta, Média, Baixa)
  - Categoria
